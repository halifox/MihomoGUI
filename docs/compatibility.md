# 兼容性验证范围

最低部署目标为 macOS 13，自动发布仅为 arm64。`scripts/check-compatibility.py` 检查包内三个 Mach-O 的实际架构、macOS 平台和最低系统版本，并核对 Info.plist；任何一个程序要求高于 macOS 13 都会阻止构建。手动 Intel 构建执行相同门禁，但资源清单尚无固定的 Intel 内核。

2026-11-15 本地验证环境：macOS 26.7.1（25G241）、arm64，Xcode 26.5 SDK。三个程序的架构均为 arm64；GUI 与辅助程序的 minos 为 13.0，内核为 11.0。此前完整构建及隔离内核交互回归通过。此记录只证明该环境及包元数据，不证明其他系统的运行行为。

尚未完成 macOS 13 实机、Intel 实机及跨系统 GUI/管理员服务运行测试。当前 CI 只运行 macOS 26 ARM，不能以部署目标或交叉编译代替上述验证。发布维护者应在对应机器记录提交号、系统版本、架构、内核版本、构建结果及核心交互结果，再更新支持声明。
