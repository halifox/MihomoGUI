# 回归验证

先运行 `bash scripts/build.sh`，再运行以下检查。需要对应架构的内核和 GEO 资源；准备步骤见 README。交互检查只使用临时目录、回环端口和独立内核，不安装或操作系统服务。运行环境须允许监听本机回环端口。

| 命令 | 关键失败路径 |
| --- | --- |
| `bash scripts/check-interactions.sh` | 损坏配置原始备份、未来格式拒绝覆盖、控制接口认证、额外字段协议覆盖、订阅取消与下载超限清理、进程与 XPC 超时、丢失热更新响应后的不确定状态和重开恢复、节点引用、事务逐写入边界回滚与磁盘中断状态的幂等恢复、真实内核配置及 provider 重载 |
| `bash scripts/check-runtime-recovery.sh` | 使用真实模型与控制接口、模拟特权边界，验证系统配置写入前失败、写入后回复丢失、恢复写入失败及安装成功后运行快照写入失败时的磁盘/内核/标记一致性；不操作系统服务 |
| `python3 scripts/check-resources.py` | 源资源/复制资源被改写、清单与下载收据不符、缺少收据、手动未验证资源不得声明上游身份 |
| `python3 scripts/check-release.py` | 草稿/公开状态、附件冲突与半上传、摘要和来源证明错误、标签变化、查询权限与传输失败；使用模拟 gh，不创建远端 Release |
| `python3 scripts/check-compatibility.py` | 包内三个程序的架构与最低系统版本；构建自动执行，不代替实机测试 |

交互、运行恢复、资源及发布失败检查已接入构建工作流。测试失败应阻止后续公证与发布；不能用构建成功代替交互回归成功。新增回归优先放入现有脚本，复现实际数据契约或失败边界，不依赖生产订阅或真实秘密。

隔离测试不覆盖管理员弹窗、launchd 安装/卸载、真实 TUN、睡眠恢复、多 VPN 共存及系统代理恢复；这些仍需按[系统行为验证记录](system-validation.md)完成独立实机验收。兼容性范围见 [compatibility.md](compatibility.md)。
