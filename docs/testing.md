# 回归验证

先运行 `bash scripts/build.sh`，再运行以下检查。需要对应架构的内核和 GEO 资源；准备步骤见 README。交互检查只使用临时目录、回环端口和独立内核，不安装或操作系统服务。运行环境须允许监听本机回环端口。

| 命令 | 关键失败路径 |
| --- | --- |
| `bash scripts/check-interactions.sh` | 损坏配置原始备份、未来格式拒绝覆盖、控制接口认证、实际编码/base64请求容量边界与客户端/辅助上限一致性、规则集地址默认遮蔽/URL与请求头秘密控件断言、额外字段协议覆盖、订阅取消与下载超限清理、内置GEO内容更新与旧标记迁移/自定义来源隔离/无变化不重写、普通命令64MiB混合输出的内存增量上限/退出诊断/继承句柄不阻塞、进程与 XPC 超时、单机服务归属的首次/同UID/跨UID/无记录残留/损坏与不可信记录拒绝、特权输入实际累计字节限制/增长流/恰好上限与超一字节/初始超限文件、辅助排队超时单次回复/过期输入拒绝/累计绝对截止预算/客户端预算上限、丢失热更新响应后的不确定状态和重开恢复、节点及带选项的子规则代理组引用、子规则分派与出口引用区分、事务逐写入边界回滚与磁盘中断状态的幂等恢复、恢复清单路径穿越/符号链接/重复及保留路径拒绝且原文件不变、规则事务部分替换中断/清单不匹配拒绝/重复恢复、真实内核配置及 provider 重载、启动健康检查的版本/监听PID/响应上限/IPv4与IPv6通配监听、选择接口回读、稳定别名在订阅/节点重排后保持选择及旧位置别名迁移 |
| `bash scripts/check-runtime-recovery.sh` | 使用真实模型与控制接口、模拟特权边界，验证各订阅均小于16MiB但合并超出32MiB请求时不提交任何文件、单个/全部订阅更新时失效节点引用协调与原子保存（获取边界使用替身，生成配置由真实内核校验）、系统配置写入前失败、写入后回复丢失、恢复写入失败及安装成功后运行快照写入失败、提交成功后恢复标记清理失败、选择请求拒绝/回读不一致/重试、规则准备回复丢失/恢复失败/重开后沿原事务恢复、旧别名运行快照迁移及未来格式下只读监控/停止时的磁盘/内核/规则/标记一致性；不操作系统服务 |
| `python3 scripts/check-resources.py` | 源资源/复制资源被改写、清单与下载收据不符、缺少收据、手动未验证资源不得声明上游身份 |
| `python3 scripts/check-release.py` | 草稿/公开状态、附件冲突与半上传、摘要和来源证明错误、标签变化、查询权限与传输失败；使用模拟 gh，不创建远端 Release |
| `python3 scripts/check-compatibility.py` | 包内三个程序的架构与最低系统版本；构建自动执行，不代替实机测试 |

交互、运行恢复、资源及发布失败检查已接入构建工作流。测试失败应阻止后续公证与发布；不能用构建成功代替交互回归成功。新增回归优先放入现有脚本，复现实际数据契约或失败边界，不依赖生产订阅或真实秘密。

隔离测试不覆盖管理员弹窗、launchd 安装/卸载、真实 TUN、睡眠恢复、多 VPN 共存及系统代理恢复；这些仍需按[系统行为验证记录](system-validation.md)完成独立实机验收。兼容性范围见 [compatibility.md](compatibility.md)。
